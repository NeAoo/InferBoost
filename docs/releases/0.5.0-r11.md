# InferBoost 0.5.0-r11

- 源码：https://github.com/NeAoo/InferBoost
- 目标镜像：`ghcr.io/neaoo/inferboost:0.5.0-cu130-r11`
- 架构：Linux amd64；NVIDIA SM80 及以上，FP8 配方需满足额外硬件条件。
- 下载状态：请以 GitHub 发布记录和 GHCR 包页面为准；仓库上传、匿名拉取与目标 GPU 验收分别记录。
- 模型权重不包含在镜像中；使用者挂载完整模型和可选 MTP。
- 首次量化需要读取固定版本的 PerfectBlend 校准数据，可配置离线快照。已有量化模型的直接加速不需要下载校准数据。
- 本次发布以 CPU、依赖导入和容器入口检查为验收范围，不新增 GPU 性能或完整链路结论。
- 正式开源许可证尚未确定，见仓库许可说明；第三方软件保留各自许可。

## 快速使用

上传并通过匿名拉取验证后，可执行 README 中的 `docker run` 和 `docker exec ... quickstart`。使用 Docker 安装器时，传入本版本镜像及发布后的完整 registry digest。

工作卷必须位于自己的持久磁盘。升级使用新工作目录，保留原目录的任务与结果。
