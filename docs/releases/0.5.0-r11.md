## 快速使用

公开可见性开启并通过匿名拉取验证后，可执行 README 中的 `docker run` 和 `docker exec ... quickstart`。使用 Docker 安装器时，在克隆的源码目录运行以下命令，并替换两个宿主路径：

```bash
bash install.sh --runtime docker \
  --image ghcr.io/neaoo/inferboost:0.5.0-cu130-r11 \
  --digest sha256:27879ac1ec5df4220a127c7e0471dcad1d74d25c1d80c0c242d929796980c03d \
  --models /absolute/models \
  --workspace /absolute/persistent-work

~/.local/bin/inferboost
```

工作卷必须位于自己的持久磁盘。升级使用新工作目录，保留原目录的任务与结果。
